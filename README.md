## ✨ 核心功能

### 📊 应用使用追踪
- **后台静默记录**：自动追踪每个窗口的使用时长，无需手动操作
- **智能空闲检测**：5 分钟无操作自动暂停计时
- **浏览器识别**：自动提取浏览器页面标题
- **应用图标**：自动提取 exe 原生图标，一目了然

### 🤖 AI 智能分类
- **多服务商支持**：DeepSeek / Kimi (Moonshot) / OpenAI / 本地 Ollama / 自定义
- **自动分类**：对热门未分类应用自动归类（启动时 + 每小时）
- **手动微调**：自定义分类、颜色、图标，随时调整

### 📈 统计看板
- **今日概览**：活跃时长、应用数、当前会话实时刷新
- **日视图**：24 小时活跃度时间线 + Top 应用排行
- **周视图**：7 天趋势对比，支持翻页
- **月视图**：GitHub 风格热力日历
- **本周对比**：本周 vs 上周逐日对比

### 📅 Notion 风格日历
- **月历网格**：日期格 + 任务条，支持多日任务
- **拖拽延长**：拖动任务条右边缘延长任务日期
- **任务详情**：多文本字段 + 评论区
- **字段自适应**：文本框随内容自动增高（Notion 同款体验）

### 🧠 AI 行为分析
- **智能报告**：每日 / 每周 / 每月使用分析
- **模式识别**：发现碎片化使用、娱乐占比过高等问题
- **改进建议**：2-3 条具体可执行的优化建议

### 🎨 个性化
- **三档主题**：暗色 / 亮色 / 跟随系统
- **自定义分类**：图标、颜色、排序完全自由
- **系统托盘**：最小化到托盘，右键快捷菜单

## 📦 安装

### 方式一：直接下载（推荐）

前往 [Releases 页面](https://github.com/libertasCat/Pulse/releases) 下载：

- **`Pulse_v0.2.0.zip`** — 完整版，解压后运行 `Pulse.exe`

> ⚠️ 首次运行 Windows SmartScreen 可能提示"已保护你的电脑"，
> 点击 **更多信息 → 仍要运行** 即可（未签名应用的正常现象）。

### 方式二：源码运行

```bash
# 需要 Python 3.10+ 和 conda/pip
git clone https://github.com/libertasCat/Pulse.git
cd Pulse

# 创建虚拟环境并安装依赖
conda create -n Pulse python=3.10 -y
conda activate Pulse
pip install -r requirements.txt

# 启动
python main.py
```

## 🚀 快速上手

### 第 1 步：启动
运行 `Pulse.exe`，应用自动开始在后台追踪你的应用使用。

### 第 2 步：配置 AI（可选）
进入 **设置 → AI 配置**：
1. 选择服务商（如 DeepSeek / Kimi）
2. 填入你的 API Key
3. 选择或输入模型名
4. 点击保存

### 第 3 步：管理分类
进入 **分类** 页面：
- 点击 **🤖 分类** 让 AI 自动归类热门应用
- 手动为应用分配分类（图标 + 名称 + 使用时长一目了然）

### 第 4 步：使用日历
进入 **日历** 页面：
- 点击格子左上角 **+** 或双击空格创建任务
- 点击任务条查看详情、编辑字段、发表评论
- 拖动任务条右边缘延长任务日期

### 第 5 步：AI 分析
进入 **仪表盘 → AI 分析** 标签页：
- 选择周期（今日 / 本周 / 本月）
- 点击 **🤖 生成分析**，获取使用报告和改进建议

## 📁 数据存储

所有数据保存在本地，**完全离线**，不会上传：

```
~/.pulse/
├── pulse.db      # SQLite 数据库（使用记录、分类、日历任务）
├── config.json   # 配置文件（API Key、主题等）
├── icons/        # 应用图标缓存
└── pulse.log     # 运行日志
```

> 数据保留策略：默认保留 180 天，可在 **设置 → 数据清理** 中调整。

## ❓ 常见问题

**Q: 为什么显示的时间不准？**
A: Pulse 每秒轮询一次前台窗口，可能存在 1-2 秒误差；空闲 5 分钟不计时。

**Q: AI 分类报错？**
A: 检查设置页 API Key 是否正确、余额是否充足；首次使用会自动安装 openai 包。

**Q: 数据会泄露吗？**
A: 不会。所有数据本地存储；AI 调用仅发送进程名和窗口标题用于分类，不发送具体内容。

**Q: 如何卸载？**
A: 删除程序目录 + `~/.pulse/` 文件夹即可完全移除。

**Q: 能用于 macOS 吗？**
A: 目前仅支持 Windows 10/11，macOS 支持在规划中。
