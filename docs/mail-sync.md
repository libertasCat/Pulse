# 网易邮箱多设备同步

设置 → 多设备邮箱同步，支持 163.com、126.com、yeah.net。先在网页版邮箱开启
IMAP/SMTP 服务，使用客户端授权码登录。同步使用 IMAP over TLS，不通过 SMTP 发信。
现有的邮件提醒功能与同步分别配置。

## 三种操作

- **立即双向同步**：先下载、合并，再上传本机最新状态。
- **从邮箱同步**：只下载并合并，保留本机尚未上传的记录，不上传任何数据。
- **用本机覆盖邮箱**：以本机状态为准，邮箱独有的记录会标记删除。需要点击确认；
  其他设备下次同步时会应用删除。旧同步邮件仍保留，普通邮件不会被删除。

自动同步仅在 Pulse 桌面程序运行时生效；启动后约 3 秒首次执行，此后按设置间隔执行，
默认 5 分钟。关闭窗口留在菜单栏/托盘时继续同步，退出程序后停止。网络不可用时保留本机
数据，下次自动或手动同步会重试。网络任务在后台线程运行，按钮在同步期间禁用。

## 多设备设置

每台设备安装支持邮箱同步的 Pulse，填写同一邮箱。同步密码必须相同；留空时使用授权码
作为加密密码，所以此时各设备必须填写相同授权码。使用不同的客户端授权码时，请显式设置
相同的同步密码。已有数据包不能用新密码解密，因此不要只在一台设备上更改同步密码。

源码运行时，如果尚未保存凭据，会从项目根目录的 authroize.txt 读取授权码。
保存后凭据位于本机数据目录的 sync-secrets.json，POSIX 系统限制为仅当前用户读写；
不会写入普通配置、同步数据包、源码或日志。授权码文件已加入 Git 忽略列表。
sync-device-id 是本机身份，不要把它复制给其他设备。

## 数据与冲突

同步应用使用记录、分类、分类映射、任务、内容块、评论、清单和图片附件。
各设备保持独立 SQLite 数据库，通过稳定记录标识合并；本地整数 ID 不会互相覆盖。
删除以墓碑记录传播，已删除的数据不会仅因读取旧同步包而复活。
API Key、邮箱凭据、登录自启动和外观设置不参与同步。

同时修改同一记录时，使用逻辑版本和设备标识确定一个一致的结果，并将被替换的本地内容
保留在数据库的 pulse_sync_conflicts 表中。导入或覆盖前会在数据目录的 sync-backups
创建数据库备份；旧图片文件不会因同步被清理。备份和冲突记录供人工恢复，目前没有恢复界面。

传输使用压缩后加密的完整快照，并非逐条实时传输。每封邮件保存一个分片；
只有完整且校验通过的快照才会导入。中途失败时仍可使用上一份完整快照。
没有变化时不重复上传。文件夹固定为 PulseSync，客户端只读取其中的同步协议邮件，
保留各设备最新完整快照用于合并，不访问收件箱。

## 当前限制

- 单次未压缩同步快照最多 20 MiB，含编码后的附件；超限会明确报错，不覆盖旧邮箱版本。
- 同步文件夹最多扫描 10000 封邮件。长期使用应在保留各设备最新完整分片组的前提下，
  手工将旧版本移到其他文件夹。程序不自动删除历史同步邮件。
- 本地备份也需按需要手工清理，备份文件包含明文本地数据。
- 提醒发送状态会同步，但同时在线的设备仍可能同时触发相同提醒。
- 设备系统时间不会决定修改胜负；并发修改不会自动进行文字级合并。
