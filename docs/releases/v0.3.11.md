# Pulse v0.3.11

任务卡片新增图片内容块：

- 在文本字段中按 Ctrl+V 粘贴截图，在字段下方插入图片。
- 支持 PNG、JPEG、BMP、WebP 本地导入，以及“粘贴图片”按钮。
- 图片等比例显示，点击查看原图，支持单独删除。
- 图片本地持久化，关闭任务后恢复；删除任务清理对应附件。
- 旧数据库自动迁移，保留已有文本字段。

Windows 完整 ZIP 包包含 Python、Qt、SQLite、SSL、AI 客户端和 VC++ 运行库。
解压到全新目录后运行 Pulse.exe，请完整保留 _internal 文件夹。

图片位于数据目录的 attachments/calendar/；备份时请同时保存 pulse.db 和 attachments 文件夹。

发布验证：源码图片回归测试，以及最终 ZIP 解压后的 Qt/SSL/数据库/AI 客户端加载和任务图片粘贴、恢复、渲染、清理自检。
