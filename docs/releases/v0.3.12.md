## 跨设备与同步

- 合入 macOS 应用监控、空闲检测、图标与登录自启动适配。
- 网易邮箱加密同步，支持双向合并、从邮箱同步及本机覆盖邮箱。
- 同步期间锁定输入，避免重复操作；覆盖操作二次确认，按钮支持亮暗主题与键盘焦点。
- Windows 包包含 Qt、SSL、SQLite、AI 客户端及加密依赖。

## 下载与使用

- Windows：下载 Windows x64 ZIP，完整解压后运行 `Pulse/Pulse.exe`，不要只移动 exe。
- Apple Silicon（M 系列）：下载 macOS arm64 ZIP，将 `Pulse.app` 移至“应用程序”。
- Intel Mac：下载 macOS x86_64 ZIP。两种 Mac 包分别原生构建，不是通用二进制。
- macOS 应用尚未使用 Apple 开发者证书签名或公证。仅从本仓库下载并确认来源后，根据系统“隐私与安全性”的提示允许打开。监控窗口标题需授予辅助功能权限；没有权限时会降级。
- 先退出托盘／菜单栏旧实例。升级前建议备份数据目录，包括 `pulse.db`、`attachments`、同步状态和配置；安装目录不包含你的个人数据。
- 邮箱同步已通过离线合并与加解密测试，未使用个人邮箱进行端到端测试。Mac 包的自动自检不等同于真实桌面权限和所有系统版本的实机验证。
